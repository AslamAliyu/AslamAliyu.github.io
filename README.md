# aslamaliyu.com

Personal portfolio site for Aslam Aliyu, published with GitHub Pages at
[www.aslamaliyu.com](https://www.aslamaliyu.com/) (custom domain set in `CNAME`).

## Structure

- `index.html`: the whole homepage (inline CSS and JavaScript)
- `3pi-robot.html`, `autonomous-car.html`, `multi-cycle-arm.html`: project detail pages
- `images/portfolio-img/`: page images
- `assets/`: images and other static files used by the detail pages
- `docs/`: downloadable resume and project report PDFs

## Local preview

    python3 -m http.server 8000

Then open http://localhost:8000.
