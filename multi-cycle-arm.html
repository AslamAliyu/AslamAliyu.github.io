Project · Embedded Systems

Multi-Cycle ARM Processor

Team Lead · VHDL on FPGA

September 2021 – December 2021

Tools

VHDL · Xilinx Vivado · Basys 3 FPGA · ModelSim

Objective

Design and implement a fully functional 32-bit ARM processor supporting instruction fetch, decode, execute, memory, and write-back stages using a multi-cycle architecture. Validate through behavioral simulation and FPGA deployment.

Components and modules

  • Register File: 16 general-purpose registers, including custom logic for R15 (PC + 8 override)
  • Controller: FSM logic for instruction decoding and control signal generation
  • Datapath: Executes instructions via ALU, Shifter, Memory, and Register File
  • Memory: Unified instruction and data memory with external program file support
  • Testbench: Simulated instruction sequences for data processing, memory, and branching

Supported features

  • All 32-bit ARMv4 instruction formats: data processing, LDR/STR, B/BL
  • ALU operations, shifting, and carry logic
  • Immediate values, PC-relative branches, and memory access
  • Instruction decoder with conditional execution (via ALU flags)
  • Hardware-mapped switches to select memory addresses on the Basys 3

Technical highlights

  • Compiled and synthesized with Vivado for the FPGA
  • Functional simulation confirmed correct signal timing and control behavior
  • Clocked FSM controller with decode and execute separation
  • Top-level file loads instructions from an external program.txt

Outcomes

  • Multi-cycle pipeline control with verified ALU flags and memory alignment
  • R15 override logic for accurate PC behavior
  • Demonstrated on the Basys 3 board in the final project presentation
